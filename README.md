> **💡 ข้อมูลไม่ทับกันแน่นอน 100%:**

### 🚀 ขั้นตอนการใช้งานครั้งแรก (ทำแค่ครั้งเดียว):
1. **เปิดลิงก์:** [https://sorawitsongs-ops.github.io/TIME-SHEET-APNS-FORM/](https://sorawitsongs-ops.github.io/TIME-SHEET-APNS-FORM/) บนมือถือหรือคอมพิวเตอร์ของตัวเอง
2. **แก้ไขข้อมูลส่วนตัว:**
   - เปลี่ยน **ชื่อ-สกุล** เป็นชื่อของตัวเอง
   - เปลี่ยน **รหัสพนักงาน, แผนก, ตำแหน่ง, สังกัด** ให้ถูกต้อง
3. **กดบันทึก:** คลิกปุ่ม **"บันทึกข้อมูลเดือนนี้"** (หรือปุ่มบันทึกสีเขียวลอยมุมขวาล่างบนมือถือ)
4. **เสร็จสิ้น!** ครั้งถัดไปที่เปิดเข้ามาใหม่ เบราว์เซอร์ในเครื่องจะจำข้อมูลของคุณไว้ตลอดไป

## ✨ ฟีเจอร์เด่นของระบบ

- **📑 แท็บแยกรายเดือน:** สลับดูและกรอกข้อมูลแยกตามเดือน (ม.ค. - ธ.ค.) หรือกดเลือกเดือนย้อนหลัง/ล่วงหน้าได้อิสระ
- **📅 ปฏิทินวันหยุดราชการไทย:** ดึงข้อมูลวันหยุดตามประกาศราชการไทยอัตโนมัติ แสดงวันหยุดและไฮไลต์วันเสาร์-อาทิตย์ให้พร้อม
- **🕒 เติมเวลาทำงานรวดเร็ว:** มีปุ่ม **"🕒 เติมเวลา 08:30 - 17:30"** กดคลิกเดียวเติมเวลาให้ทุกวันทำงานในเดือนนั้นทันที
- **📱 ใช้งานบนมือถือได้ลื่นไหล (Mobile Responsive):**
  - **ตรึงคอลัมน์ "วันที่" (Sticky):** เวลาปัดตารางแนวนอนไปกรอกเวลาหรือ OT คอลัมน์วันที่จะยังอยู่ด้านซ้าย ไม่หลงแถว
  - **ปุ่มบันทึกลอย (Floating Button):** เลื่อนลงไปกรอกถึงวันที่ 30 ก็กดบันทึกได้ทันทีไม่ต้องเลื่อนจอกลับขึ้นไปบนสุด
- **📥 ส่งออก Excel (.xls):** โหลดไฟล์ Excel ไปใช้งานต่อได้ทันที ฟอร์แมตตรงตามแบบฟอร์มบริษัท พร้อมส่วนลายเซ็นท้ายเอกสาร
- **🖨️ พิมพ์ / บันทึก PDF (A4 Portrait):** กดปุ่มเดียวสั่งพิมพ์หรือ Save as PDF ออกมาเป็นกระดาษ A4 สะอาดตา ไม่มี URL หรือหัวกระดาษเบราว์เซอร์มารบกวน
